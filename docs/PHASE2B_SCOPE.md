## 1. ملف المدرسة + Storage

| البند | المحتوى |
|---|---|
| **Scope** | بيانات تواصل موسّعة (عنوان، هاتف E.164، بريد، موقع، اسم المدير للعرض)؛ شعار؛ ختم؛ توقيعات بصفاتها. للعرض والوثائق (الشهادات في المرحلة 6)، لا للتفويض |
| **Business rules** | الأصل لا يُستبدل ولا يُحذف: رفع جديد ينشئ نسخة ويُحيل السابقة إلى `retired` (الشهادة القديمة تشير إلى النسخة التي طُبعت بها — مرحلة 6)؛ أصل نشط واحد لكل (مدرسة، نوع) للشعار والختم، ولكل (مدرسة، صفة) للتوقيع؛ PNG/JPEG فقط، ≤ 1MB، أبعاد معقولة؛ المدرسة المؤرشفة للقراءة فقط |
| **Data model** | `school_profiles` [S] (`school_id` PK/FK، `address`، `phone_e164` CHECK E.164، `email`، `website`، `principal_display_name`، الأعمدة المشتركة)؛ `school_assets` [S] (`id`، `school_id`، `kind` CHECK `logo/stamp/signature`، `signer_title` (للتوقيع)، `object_path` فريد، `content_type`، `byte_size`، `sha256`، `status` `active/retired`، `retired_at`، الأعمدة المشتركة)؛ فهرس فريد جزئي «نشط واحد» |
| **Authorization** | قراءة: `school.read` + نطاق المدرسة · الملف: `school.update` · الشعار: `school.update` · الختم والتوقيعات: `security.manage` (B5) |
| **RLS** | الجدولان School-level: `can_access_school(school_id)` + المفتاح؛ لا INSERT/UPDATE للعميل على `school_assets` (الدالة وحدها)؛ `storage.objects`: **لا سياسة للعميل** — الكائنات خاصة ولا تُقرأ إلا بروابط موقّعة يصدرها FastAPI بعد سؤال DB |
| **Controlled functions** | `app.register_school_asset(school, kind, signer_title, object_path, content_type, byte_size, sha256, reason)` — الصلاحية حسب النوع، النطاق، المدرسة نشطة، إحالة النشط السابق إلى `retired` ذرياً، تدقيق؛ `app.retire_school_asset(asset, reason)` |
| **API** | `GET/PATCH /schools/{id}/profile`؛ `GET /schools/{id}/assets`؛ `POST /schools/{id}/assets` (multipart: يتحقق، يرفع، ثم الدالة — فشلها يحذف الكائن تعويضاً، نمط الـSaga)؛ `GET /assets/{id}/url` (رابط موقّع بعد قراءة الصف تحت RLS)؛ `POST /assets/{id}/retire` |
| **Web** | قسم «ملف المدرسة» في صفحة المدرسة: البيانات، معاينة الأصول النشطة، رفع نسخة جديدة، سجل النسخ |
| **Audit** | T7 على الجدولين؛ الرفع والإحالة بسبب؛ لا تُنسخ محتويات الملفات إلى التدقيق (المسار والبصمة فقط) |
| **Invariants** | نشط واحد لكل (مدرسة، نوع/صفة)؛ مسار الكائن يبدأ بـ`{tenant}/{school}/` (CHECK)؛ لا إعادة تنشيط لنسخة متقاعدة |
| **Tests** | pgTAP: عزل، الصلاحية لكل نوع (الختم بلا `security.manage` ← رفض)، النشط الواحد، الإحالة الذرية؛ pytest: النوع والحجم المرفوضان، التعويض عند فشل الدالة، الرابط الموقّع لا يُصدر لأصل غير مرئي، انتهاء صلاحيته؛ E2E: رفع ومعاينة |
| **Dependencies** | Storage محلياً وفي CI (B6)؛ المرحلة 6 (الشهادات) تستهلك الأصول |
| **Gate criteria** | الضوابط السلبية؛ لا كائن بلا صف ولا صف بلا كائن بعد أي فشل؛ الاستعادة تشمل فحص الاتساق |

|---|---|

| **Business rules** | كل خطوة تستدعي المسارات نفسها (لا endpoint خاص بالمعالج يكتب)؛ التقدّم **مشتق** من البيانات؛ **لا يغيّر `ready_for_enrollment`** (2A)؛ «اكتمال الإعداد» مؤشر مستقل بشروط كل خطوة. قابل للتخطي: الأصول، الدوام، المواد (لا يمنع التسجيل)؛ غير قابل: ما تشترطه الجاهزية |
| **Data model** | لا جداول |
| **Authorization / RLS** | لا شيء جديد: كل خطوة تخضع لمفاتيحها ونطاقها؛ الخطوة غير المسموحة تظهر للقراءة أو مخفية، والخادم يرفض |
| **API** | `GET /schools/{id}/setup-progress` (مشتق، قراءة فقط، بقاعدة 403 للجاهزية نفسها) |
| **Web** | `/setup/schools/:id/wizard` |
| **Tests** | E2E: مدير الـTenant ينهي المعالج من الصفر؛ مدير المدرسة يرى خطواته فقط؛ تجاوز المعالج بالـAPI لا يمنح شيئاً |
| **Gate criteria** | معيار المرحلة 2 في PLAN: «إعداد مدرسة كاملة من الصفر عبر الواجهة فقط» يُثبت بهذا الـE2E |

## 6. Impact analysis

**الجداول الجديدة (8):** `school_profiles`، `school_assets`، `calendar_weekdays`، `calendar_exceptions`، `subjects`، `grade_subjects`، `bell_schedules`، `periods` — Foundation 30 ← 38. كل جدول: DD أولاً، RLS + FORCE، منح أعمدة صريح (secure-by-default)، T6/T7، اختبار عزل، تحديث الحراس الدائمة (`13` قائمة الجداول، `11` تغطية T7، `20` سجل الأعمدة و allowlist، `31` السياسات والـtriggers والدوال، `23` إن تغيّر الكتالوج، بصمة الاستعادة).

**الصلاحيات:** مفتاحان جديدان فقط إن اعتُمد B10 (`subject.read`، `subject.manage`)؛ لا تعديل على أي مفتاح قائم؛ توزيعهما (B15): `subject.manage` لـ`tenant_admin`/`group_manager`/`school_admin`، `subject.read` لهم وللسكرتير والمعلم والمحاسب والمرشد. يمر بـT8 كالمعتاد.

**الدوال المتحكَّم بها (تقديرياً):** تسجيل الأصل وإحالته، ونسخ ثلاثة أنواع إلى سنة جديدة؛ والقراءة المساعدة `is_school_day`.

**البيئة:** تفعيل Storage محلياً (`supabase start` بلا `-x storage-api`) وفي CI؛ `scripts/dev-up.sh` المحلية.
